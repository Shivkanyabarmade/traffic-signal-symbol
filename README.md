# 🚦 Traffic Signal Logo

This project is a simple **Traffic Signal Logo** designed using **HTML and CSS**.  
It displays three circular lights — **Red, Yellow, and Green** — arranged vertically inside a traffic signal box with a pole.

## Technologies Used
- HTML5
- CSS3

## Features
- Three colored signal lights
- Clean and simple layout
- Pure HTML & CSS (no JavaScript)

## How to Run
Open the `index.html` file in any web browser.
